# Joel Iniguez - Portfolio Website

A modern, responsive portfolio website built with Next.js, TypeScript, and Tailwind CSS, showcasing full-stack development expertise and AI engineering capabilities.

## Technologies Used

- **Frontend**: Next.js 14, React 18, TypeScript
- **Styling**: Tailwind CSS, Radix UI Components
- **Build Tools**: Webpack, PostCSS
- **Development**: Hot Module Replacement, Turbopack support
